# Phase 9.5: Deferred Release — стабильный реестр врагов
- Status: accepted
- Цель: устранить мутацию `EnemyController.Active` во время итерации. Смерть врага больше не возвращает его в пул синхронно — освобождение вынесено в `EnemyKillSystem.LateUpdate`, поэтому `Active` стабилен на всём протяжении игровой логики кадра, и циклы итерируют его напрямую без снапшотов.

## Задачи (порядок = приоритет)
- T062: `EnemyKillSystem` — очередь мёртвых врагов + флаш `pool.Release` в `LateUpdate`.
- T063: `EnemyController`/`WaveSpawner` — смерть ставит врага в очередь (`Enqueue`), а не освобождает сразу.
- T064: `TurretController` — пропуск мёртвых врагов при поиске цели.
- T065: `ExplosionOnHitHandler` — убрать снапшот `_buffer`, перебор `Active` напрямую.
