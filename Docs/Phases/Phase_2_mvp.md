# Phase 2: Боевой цикл — враг и снаряд
- Status: in-progress
- Цель: турель Hammer стреляет снарядом в ближайшего врага; враг Runner берётся из
  пула, бежит к игроку, умирает от урона через `IDamageable` и возвращается в пул.

## Задачи (порядок = приоритет)
- T008: Namespace `TankSurvival.*` на 7 существующих `.cs` (+ `using` кросс-ссылок).
- T009: SO-данные боя — `EnemyData`, `TurretData`, `DeliveryModuleData`.
- T010: Generic-пул — `IPoolable` + `PoolManager`.
- T011: Враг — `EnemyController` + `EnemyHealth` (движение, melee, HP, смерть→пул).
- T012: Снаряд — `Projectile` (пул, полёт, контакт→урон, возврат в пул).
- T013: Турель — `TurretController` + `DeliveryHandler` + `ProjectileDeliveryHandler`.
- T014: `GameBootstrap` — prewarm пулов, временный спавн, связка турели.

## Smoke-тест (проверяет человек)
- [ ] Проект компилируется без ошибок и предупреждений.
- [ ] Все `.cs` имеют namespace `TankSurvival.*`.
- [ ] Турень авто-стреляет в ближайшего врага (~2 выстр/сек, aps).
- [ ] Снаряд летит и при попадании наносит урон (Runner 20 HP гибнет с одного выстрела, урон 30).
- [ ] Runner бежит к игроку и наносит 5 урона при контакте (не чаще 1/сек).
- [ ] Враг при HP ≤ 0 деактивируется (возврат в пул); число активных объектов в иерархии не растёт.
- [ ] Снаряд после попадания/пролёта деактивируется (возврат в пул).
- [ ] В консоли нет ошибок; нет `Instantiate`/`Destroy` в игровом цикле.
