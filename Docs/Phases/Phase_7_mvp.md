## Smoke-тест (проверяет человек)
- [ ] Проект компилируется без ошибок и предупреждений.
- [ ] HUD показывает HP (текущее/макс), прогресс XP, уровень, волну (текущая/всего), убийства.
- [ ] Убийство врага инкрементит счётчик убийств; урон игроку обновляет HP-бар; XP-бар растёт от убийств.
- [ ] Зачистка волны → номер волны растёт; после последней волны — `RoundEndUI` показывает «Победа».
- [ ] HP игрока = 0 → `RoundEndUI` показывает «Поражение».
- [ ] Кнопка рестарта в `RoundEndUI` запускает новый раунд без перезагрузки сцены (состояние сброшено, `Time.timeScale = 1`).
- [ ] Смена `selectedChassis`/`selectedTurret`/`selectedDifficulty` в `SessionState` меняет статы/турель/число волн следующего раунда.
- [ ] Полный smoke по прогонам A (Standart+Hammer), B (Standart+Beam), C (Fat+любая турель): оба врага (Runner+Tank) в раунде, число объектов в иерархии не растёт, консоль чистая.
