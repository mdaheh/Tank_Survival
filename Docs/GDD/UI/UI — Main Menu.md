# Main Menu

Первый экран игры.

## Визуал

- **Фон:** статичный.
- **Центр:** вращающееся 3D-превью текущего танка (шасси + турель).
- **Логотип игры:** сверху по центру.
- **Кнопки:** снизу по центру.

## Элементы

| Элемент | Позиция | Действие |
|---|---|---|
| Логотип | Верх | — |
| Превью танка | Центр | Вращение, 360° |
| Кнопка START | Низ, левая | → Difficulty Selection |
| Кнопка HANGAR | Низ, правая | → Hangar |

## Тексты

| RU | EN |
|---|---|
| СТАРТ | START |
| АНГАР | HANGAR |

## Особенности

- Превью обновляется, если игрок сменил шасси/турель в ангаре.
- При первом запуске показывается только базовый танк (Standart + Молоток).
- Нет кнопки «Настройки» (добавится позже, если понадобится).
