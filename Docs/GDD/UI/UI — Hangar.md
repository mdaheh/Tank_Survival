# Hangar

Экран выбора шасси и турели.

## Визуал

- **Центр:** вращающееся 3D-превью танка.
- **Левая панель:** список шасси.
- **Правая панель:** список турелей.
- **Низ:** кнопка НАЗАД.

## Левая панель — Шасси

| Элемент | Действие |
|---|---|
| Список всех 4 шасси | Клик → выбор |
| Иконка + название | — |
| Заблокированные: серый + замок | Клик недоступен |
| Текущий выбор: подсвечен | — |

## Правая панель — Турели

| Элемент | Действие |
|---|---|
| Список всех 11 турелей | Клик → выбор |
| Иконка + название | — |
| Заблокированные: серый + замок | Клик недоступен |
| Текущий выбор: подсвечен | — |

## Превью

- Обновляется **мгновенно** при смене шасси или турели.
- Показывает **комбинацию**: корпус + башня.
- Вращается автоматически.

## Навигация

- **НАЗАД** → Main Menu.
- Выбор **сохраняется** между посещениями ангара.
- Выбор **применяется** к следующему забегу.

## Правила

- Недоступные варианты показываются (не скрываются).
- Порядок в списке: базовые → специализации.
