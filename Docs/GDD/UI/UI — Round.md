# Round

Основной игровой экран. Включает HUD, level-up, wave reward и паузу.

## HUD (постоянно на экране)

| Элемент | Позиция | Что показывает |
|---|---|---|
| HP bar | Левый верхний | Текущее / макс. HP |
| Кнопка паузы | Правый верхний | Иконка «⏸» |
| XP bar | Внизу по центру | Прогресс до уровня |
| Уровень | Над XP bar | Текущий уровень |
| Волна | Правый верхний | «Волна 7 / 20» |
| Таймер волны | Под волной | Оставшееся время |
| Убийства | Правый верхний | Всего за забег |
| Способность | Левый нижний | Кулдаун + иконка |
| Модули | Правый нижний | Иконки OnHit |

## События

### Level-up

**Триггер:** XP bar заполнен.

1. Игра на паузу.
2. Фон затемнён.
3. Появляются **3 карточки апгрейдов**.
4. Игрок выбирает одну (клик / тап).
5. Игра снимается с паузы.

**Карточка:**
- Иконка.
- Название.
- Описание («Урон +15%»).
- Стак («2 / 5»).

### Wave reward

**Триггер:** начало волн 5, 10, 15, 20.

1. Игра на паузу.
2. Фон затемнён.
3. Появляются **3 карточки модулей**.
4. Игрок выбирает один.
5. Игра снимается с паузы.

**Карточка:**
- Иконка.
- Название («Разрывные снаряды»).
- Описание («При попадании создаёт взрыв»).
- Тег (`aoe`, `dot`, `control`).

### Смерть игрока

**Триггер:** HP = 0.

1. Игра останавливается.
2. → Round End.

## Пауза

**Триггер:** кнопка паузы в HUD / клавиша Esc.

### Визуал

- **Фон:** затемнённый Round (полупрозрачный).
- **Центр:** панель со сводкой.
- **Низ:** кнопки ПРОДОЛЖИТЬ и В МЕНЮ.

### Сводка (минималистичная)

**Прогресс забега:**
| Показатель | Пример |
|---|---|
| Уровень | 12 |
| Опыт | 245 / 258 |
| Убийств | 187 |
| Волна | 8 / 20 |

**Шасси:**
| Параметр | Значение |
|---|---|
| Название | Standart |
| HP | 100 / 100 |
| Speed | 5.0 |
| Turn | 180°/с |
| Способность | Boost (готов) |

**Турель:**
| Параметр | Значение |
|---|---|
| Название | Молоток |
| APS | 2.0 |
| Урон | 45 |
| Дальность | 6.0 |

**Апгрейды (список):**
| Название | Стак |
|---|---|
| Reinforced barrels | 3 / 5 |
| Quick bolt | 2 / 5 |

**Модули (иконки):**
| Модуль | Тег |
|---|---|
| Explosion | aoe |
| Burn | dot |

### Кнопки

| Кнопка | Действие |
|---|---|
| ПРОДОЛЖИТЬ | Снять паузу, вернуться в Round |
| В МЕНЮ | Открыть подтверждение |

### Подтверждение выхода

**Триггер:** нажата кнопка В МЕНЮ.

**Окно:**
- **Заголовок:** «Завершить забег?»
- **Текст:** «Прогресс забега будет потерян. Убийства сохранятся.»
- **Кнопки:** ДА / НЕТ.

| Кнопка | Действие |
|---|---|
| ДА | → Round End (забег завершён) |
| НЕТ | Вернуться в Pause |

### Правила

- Кнопка паузы **всегда** доступна в правом верхнем углу.
- Пауза **останавливает** время.
- Сводка **только читается** — нельзя менять апгрейды.
- Все данные обновляются **при открытии** паузы.
- Минималистичный вид, без лишних анимаций.
- Выход **требует подтверждения**.
- Прогресс забега **не сохраняется** (браузерное ограничение) грубом закрытии игры, только после завершения раунда предусмотренными методами.
- Убийства **сохраняются** в общий счётчик аккаунта.

## Визуал

- **Камера:** изометрия, следует за игроком с сглаживанием.
- **Арена:** заранее созданные уровень с минимальными количеством статичных объектов.
- **Враги:** подсветка при получении урона.

## Правила UI

- HUD не перекрывает центр экрана.
- Level-up и wave reward **полностью блокируют** управление и игра ставится на паузу.
- UI масштабируется под разрешение.
