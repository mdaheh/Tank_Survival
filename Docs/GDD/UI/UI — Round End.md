# Round End

Экран итогов забега.

## Визуал

- **Фон:** затемнённый Round.
- **Центр:** панель статистики.
- **Низ:** кнопка ПРОДОЛЖИТЬ.

## Статистика

| Показатель | Пример |
|---|---|
| Сложность | Сержант |
| Достигнутая волна | 15 / 20 |
| Убийств за забег | 342 |
| Уровень | 18 |
| Время забега | 8:24 |
| Всего убийств (аккаунт) | 12 458 |

## Кнопки

| Кнопка | Действие |
|---|---|
| ПРОДОЛЖИТЬ | → Main Menu |

## Правила

- Убийства **сохраняются** в общий счётчик.
- XP, уровень, апгрейды **обнуляются**.
- Открытия (новые шасси/турели/сложности) **проверяются** здесь.
- Если открыто что-то новое — показывается **уведомление** («Открыто: Fat», «Открыта сложность: Лейтенант»).
