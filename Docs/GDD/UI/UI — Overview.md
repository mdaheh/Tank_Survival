# UI — Обзор

## Карта экранов

```
Main Menu
├── START → Difficulty Selection
│              └── [выбор] → Round
│                            ├── [кнопка паузы] → Pause (внутри Round)
│                            │                    ├── [продолжить] → Round
│                            │                    └── [в меню] → подтверждение → Round End
│                            └── [смерть/победа] → Round End
│                                                  └── → Main Menu
└── HANGAR → Hangar
              └── [назад] → Main Menu
```

## Список экранов

| Экран | Файл | Назначение |
|---|---|---|
| Main Menu | [[UI — Main Menu]] | Точка входа |
| Hangar | [[UI — Hangar]] | Выбор шасси и турели |
| Difficulty Selection | [[UI — Difficulty Selection]] | Выбор сложности |
| Round | [[UI — Round]] | Игровой процесс + пауза |
| Round End | [[UI — Round End]] | Итоги забега |

## Общие правила

- **Стиль:** минималистичный, футуристичный.
- **Превью танка:** вращающаяся 3D-модель на экранах выбора.
- **Навигация:** кнопка НАЗАД возвращает на предыдущий экран.
- **Мультиязычность:** русский и английский.
- **Разрешение:** адаптив под 16:9 и 16:10, поддержка мобильных браузеров.
- **Пауза:** доступна в любой момент раунда.
- **Сохранение:** Сохраняется только общий счётчик убийств между раундами

## Правила переходов

| Из | В | Триггер |
|---|---|---|
| Main Menu | Difficulty Selection | Кнопка START |
| Main Menu | Hangar | Кнопка HANGAR |
| Difficulty Selection | Round | Выбор сложности |
| Hangar | Main Menu | Кнопка НАЗАД |
| Difficulty Selection | Main Menu | Кнопка НАЗАД |
| Round | Pause | Кнопка паузы / Esc |
| Pause | Round | Кнопка ПРОДОЛЖИТЬ |
| Pause | Подтверждение | Кнопка В МЕНЮ |
| Подтверждение | Round End | Кнопка ДА |
| Подтверждение | Pause | Кнопка НЕТ |
| Round | Round End | Смерть игрока или победа |
| Round End | Main Menu | Кнопка ПРОДОЛЖИТЬ |
