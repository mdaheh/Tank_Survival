# Опыт и уровни

## Получение опыта

Игрок получает XP за убийство врагов.

| Враг | Базовый XP |
|---|---|
| Runner | 1 |
| Brute | 3 |
| Shooter | 4 |
| Tank | 5 |
| Boss | 50 |

**Формула:** `XP_за_убийство = Базовый_XP × Множитель_сложности`

**Пример для Brute на Генерале:** `3 × 2.2 = 6.6 XP`

## Ожидаемый XP за забег

На сложности **Сержант** (20 волн):

| Волны | Примерный XP |
|---|---|
| 1-3 | ~70 |
| 4-9 | ~250 |
| 10-20 | ~1100 |
| **Итого** | **~1420** |

**Вывод:** игрок достигает 29-30 уровня к концу забега.

## Level-up

При достижении нового уровня:
1. Игра ставится на **паузу**.
2. Игроку предлагается **3 варианта апгрейда**.
3. Игрок выбирает **один**.
4. Игра снимается с паузы.

## Пул апгрейдов на level-up

**Источники:**
- `tag`-апгрейды (универсальные, для тега).
- `unique`-апгрейды (для конкретной турели).
- `ability`-апгрейды (для способности шасси).

**Правила пула:**
- 3 случайных апгрейда из доступных.
- Апгрейд доступен, если:
  - `required_tags` совпадают с тегами игрока.
  - Апгрейд ещё не на максимальном уровне (`max_stacks`).
  - `target_turret` / `target_chassis` / `target_ability` соответствуют текущему билду.
- Если доступно < 3 апгрейдов — показываются все.

## Level cap

**Мягкий кап — 30 уровней.**
- На 30-м уровне XP продолжает собираться, но level-up не происходит.
- Это защита от бесконечной прокачки на длинных сложностях.

## UI во время level-up

- **Фон:** затемнён.
- **Заголовок:** «Уровень N».
- **3 карточки:** иконка, название, описание, `max_stacks`.
- **Выбор:** клик / тап.
- **Отмена:** нет (обязательный выбор).

## Правила

- XP обнуляется после забега.
- Уровень обнуляется после забега.
- Level-up **не прерывает** волну — игра на паузе, потом продолжается.
- На сложностях с 50 волнами игрок может дойти до капа **до** финала.
