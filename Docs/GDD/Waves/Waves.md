# Система волн

## Параметры
| Параметр | Значение |
|---|---|
| Спавн-батч | 20 врагов фиксировано |
| Спавн-интервал | 1.5 – 5.0 сек (зависит от сложности) |
| Лимит на экране | 300 (мягкий) |
| Модульный апгрейд | каждая 5-я волна |
| Босс | каждая 10-я волна |

## Формула состава волны (базовая, ×1.0)

| Враг | Формула | Условие |
|---|---|---|
| Runner | `20 + (n-1) * 3.0` | всегда |
| Brute | `(n-3) * 2.5` | n ≥ 4 |
| Shooter | `(n-5) * 2.0` | n ≥ 6 |
| Tank | `(n-9) * 1.5` | n ≥ 10 |
| Boss | 1 | n % 10 == 0 |

**Итог:** `round(кол-во × Множитель_сложности)`

## Правила

- Каждые `interval` секунд спавнится **20 врагов**.
- Если волна требует больше — спавнится несколько батчей за раз.
- Враги спавнятся **по краям арены**.
- Волна заканчивается, когда все убиты **ИЛИ** истекло время.
- Каждая 5-я волна → выбор модуля (3 варианта).
- Каждая 10-я волна → босс в начале волны.
- Лимит 300 — **мягкий**, при превышении игра продолжается.

## Дашборд (Сержант)

```dataviewjs
const waves = [];
for (let n = 1; n <= 20; n++) {
  const runner = Math.round(20 + (n-1) * 3.0);
  const brute = n >= 4 ? Math.round((n-3) * 2.5) : 0;
  const shooter = n >= 6 ? Math.round((n-5) * 2.0) : 0;
  const tank = n >= 10 ? Math.round((n-9) * 1.5) : 0;
  const boss = n % 10 === 0 ? 1 : 0;
  const total = runner + brute + shooter + tank + boss;
  waves.push([n, runner, brute, shooter, tank, boss, total]);
}

dv.table(
  ["Волна", "Runner", "Brute", "Shooter", "Tank", "Boss", "Всего"],
  waves
);
```
