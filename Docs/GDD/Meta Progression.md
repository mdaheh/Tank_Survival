# Мета-прогрессия

Прогресс между забегами. Сохраняется в браузере (LocalStorage).

## Три типа открытий

| Тип | Счётчик | Что открывает |
|---|---|---|
| **Турели** | Убийства в ветке | Специализации |
| **Шасси** | Общие убийства | Новые шасси |
| **Сложности** | Прогресс прохождения | Новые сложности |

---

## 1. Открытие турелей

**Счётчик**: убийства, накопленные внутри ветки (см. Legend §4.3).
**Правило**: убийства на любой турели ветки — базовой или специализации —
идут в общий счётчик этой ветки. Счётчики трёх веток независимы.

| Ветка | Счётчик | Открывает |
|---|---|---|
| cannon | `cannon_kills` | Пулемёт (1500), Дробовик (2000), Бомбарда (2500), Пробивная (3000) |
| flamethrower | `flamethrower_kills` | Freezer (1500), Hellfire (2500) |
| laser | `laser_kills` | Луч (1500), Рейлган (3000) |

**Пример:**
- Игрок играет на Молотке → 500 убийств → `cannon_kills: 500`.
- Играет на Пулемёте → ещё 1000 убийств → `cannon_kills: 1500`.
- Открывается Дробовик (2000) — нужен ещё 500.

---

## 2. Открытие шасси

**Счётчик:** общие убийства за всё время с любой турелью.

| Шасси | Открытие |
|---|---|
| Standart | С начала |
| Fat | 5 000 убийств |
| Fancy | 8 000 убийств |
| Veteran | 15 000 убийств |

**Правило:** любые убийства (любая турель, любая сложность) идут в `total_kills`.

---

## 3. Открытие сложностей

**Счётчик:** прогресс прохождения.

| # | Сложность | Открытие |
|---|---|---|
| 1 | Рекрут | С начала |
| 2 | Солдат | С начала |
| 3 | Сержант | С начала |
| 4 | Лейтенант | Победа на «Сержанте» |
| 5 | Капитан | Победа на «Лейтенанте» |
| 6 | Майор | Победа на «Капитане» |
| 7 | Полковник | Победа на «Майоре» |
| 8 | Генерал | Победа на «Полковнике» |

**Правило:** сложности 4-8 открываются **последовательно**.
**Правило:** победа = **выжить на всех волнах** сложности.

---

## Что сохраняется

| Данные | Сохраняется? |
|---|---|
| `total_kills` | ✅ Да |
| `cannon_kills` | ✅ Да |
| `flamethrower_kills` | ✅ Да |
| `laser_kills` | ✅ Да |
| Открытые сложности | ✅ Да |
| Открытые шасси | ✅ Да |
| Открытые турели | ✅ Да |
| Выбор шасси/турели | ✅ Да |
| Прогресс забега (XP, уровень) | ❌ Нет |
| Текущая волна | ❌ Нет |

## Когда сохраняется

- **После завершения раунда** (смерть или победа).
- **При выходе в меню** через паузу (с подтверждением).
- **НЕ сохраняется** при грубом закрытии вкладки.

## Формат хранения

LocalStorage (JSON):

```json
{
  "total_kills": 12458,
  "cannon_kills": 3200,
  "flamethrower_kills": 800,
  "laser_kills": 1500,
  "unlocked_chassis": ["chassis_standart", "chassis_fat"],
  "unlocked_turrets": ["hammer", "machine_gun", "shotgun"],
  "unlocked_difficulties": ["recruit", "soldier", "sergeant", "lieutenant"],
  "selected_chassis": "chassis_fat",
  "selected_turret": "shotgun"
}
```

## UI мета-прогрессии

### В ангаре

- Заблокированные турели/шасси показываются **серыми с замком**.
- На карточке отображается **прогресс**: «1 200 / 1 500 убийств».
- Прогресс-бар под названием.

### На экране выбора сложности

- Заблокированные сложности **серые с замком**.
- Информация: «Победа на „Сержанте“».

### На экране Round End

- Уведомления об открытиях:
  - «Открыто: Fat»
  - «Открыта сложность: Лейтенант»

---

## Правила

- Счётчики **никогда не сбрасываются**.
- Убийства идут в счётчик **сразу при убийстве** (в памяти), сохраняются после раунда.
- Открытия проверяются **после раунда** (Round End).
- Если игрок достиг порога **внутри раунда** — открытие показывается в Round End.
